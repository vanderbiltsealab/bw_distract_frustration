# bw_distract_frustration
Data, analysis code, and research materials for *Staying With the Emotion or Redirecting Attention? Mothers’ Responses to Preschoolers’ Anger and Frustration, Children’s Momentary Affect, and Effortful Control*

Repository contents:
- `bw_distract_experimental_code.Rmd` contains the analytic code for Aim 1 
- `bw_distract_experimental_data.csv` contains the deidentified data for Aim 1 
- `bw_distract_correlational_code.Rmd` contains the analytic code for Aim 2
- `bw_distract_correlational_data.csv` contains the deidentified data for Aim 2 
- `SEA Lab_Affect Coding Protocol.pdf` includes the affect descriptors used for affect coding
